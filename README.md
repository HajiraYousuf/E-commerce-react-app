# 🛍️ E-Commerce React App

A modern and responsive **E-Commerce Web Application** built with React.
The project provides a smooth online shopping experience where users can browse products, view detailed information, manage their shopping cart, and complete orders using different payment methods.

### 🚀 Live Demo

**[View Live Website](https://e-commerce-react-app-fawn.vercel.app/)**

---

## ✨ Features

* 🏠 Modern and responsive Home Page
* 🛍️ Product listing and browsing
* 🔎 Product search and filtering
* 📦 Product Details page
* 🛒 Add products to Cart
* ➕ Increase and decrease product quantity
* 🗑️ Remove products from Cart
* 💰 Automatic cart total calculation
* 💳 Card Payment option
* 💵 Cash Payment option
* ✅ Order confirmation
* 🧹 Cart automatically clears after placing an order
* 📱 Fully responsive design
* ⚡ Fast and smooth React interface
* 💾 Cart state management with Context API
* 💡 Modern UI built with Tailwind CSS

## 💳 Payment Flow

The checkout system supports two payment methods:

### 💳 Card Payment

Users can select **Card Payment** during checkout and complete the order flow.

### 💵 Cash Payment

Users can also select **Cash Payment** and place the order without entering card information.

After a successful order:

**Payment → Order Placed → Cart Cleared → Shopping Continues**
